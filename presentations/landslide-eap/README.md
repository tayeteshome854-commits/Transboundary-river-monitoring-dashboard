# SSGI Landslide EAP workshop presentation

`SSGI_Landslide_EAP_Workshop_Presentation.pptx` is the deck for the SSGI session at the
ERCS Technical Consultation Workshop on a Landslide Early Action Protocol
(Addis Ababa, 16–17 November 2026). It is not part of the river monitoring dashboard.

The deck is generated by `build_deck.py` (slide content) using `deckkit.py` (layout helpers).
The figures are extracted from the SSGI Disaster Monitoring Center presentation PDF, which is
not stored in this repository. The two example images on slide 9 (LiDAR and aerial photograph) are
public-domain U.S. Geological Survey images stored in `assets/`; their sources are listed in
`assets/SOURCES.md`. They are not SSGI data.

## Rebuild

```bash
pip install python-pptx pymupdf pillow
python build_deck.py --dmc /path/to/DMC.pdf            # writes the .pptx next to the script
python build_deck.py --dmc /path/to/DMC.pdf --preview previews/   # also writes approximate PNG previews
```

The script reports any text that does not fit its box and exits with status 2 if there is any.
The PNG previews are drawn with Pillow and Liberation Sans (set `DECK_FONT_DIR` to the folder
holding the `LiberationSans-*.ttf` files); they approximate PowerPoint's rendering and do not
replace opening the file in PowerPoint.

Edits made directly in PowerPoint are overwritten by the next rebuild.
